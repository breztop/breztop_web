BRANCHING NARRATIVE

对话剧情小说游戏

  • 视觉小说
  • 分支对话
  • 存档读档
支持分支选择、多槽存档与多结局的视觉小说
NARRATOR

玩家通过对话和选择推进故事，选择会改变角色关系、后续选项和结局。游戏支持多槽位存档、自动存档、快进、自动播放、历史回看与结局记录。

SCENE 02冲突

THE CONFLICT

分支选择与读档需要恢复哪些状态？

角色关系、已读记录和章节进度会影响后续选项与结局。读档需要同时恢复对话节点、剧情变量和当前画面，才能继续原来的分支。

存档内容：当前节点、剧情变量、已读记录与画面状态。
03

THE SYSTEM

剧情数据与存档实现

对白、选项、条件和跳转保存在剧情节点中，由运行器读取并触发画面与声音事件。剧情变量集中管理，存档使用带版本号的状态快照，记录节点、变量、已读和画面状态；结局与章节解锁按条件计算。

SCENE 04 / PLAYER CHOICES

阅读、存档与结局功能

支持手动阅读、自动播放和快进，可保存进度并查看已达成结局。

  1. A

    开始游戏、章节推进、暂停设置和重新游玩

  2. B

    根据剧情变量和角色关系显示选项，选择后进入不同分支

  3. C

    手动选择存档槽位，查看存档信息，或使用自动存档恢复进度

  4. D

    对白逐字显示，支持快进、自动播放、历史回看和已读识别

  5. E

    随剧情切换角色立绘、表情、场景、转场、音乐和音效

  6. F

    查看结局图鉴，保留跨周目的解锁记录

SCENE 05 / NARRATIVE GRAPH

对话与存档模块

NODE 01

对话运行器

逐个读取剧情节点，处理对白、旁白、条件与跳转

NODE 02

剧情状态

集中管理剧情变量、角色关系、章节进度、已读记录与跨周目解锁状态

NODE 03

选项与分支

根据前置条件生成可用选项，把选择结果写回状态并进入对应剧情分支

NODE 04

存档与读档

使用带版本号的状态快照保存进度，供手动与自动存档读取

NODE 05

画面与音效

接收剧情事件，更新立绘、表情和背景，播放转场、音乐与音效

NODE 06

结局记录

计算多结局条件，记录已达成结局并支持图鉴查看与多周目收集
