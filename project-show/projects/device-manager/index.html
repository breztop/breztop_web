DIAGNOSTIC ISSUE

设备信息来自不同系统接口

不同系统接口返回的设备名称和能力格式并不一致，权限与热插拔也会改变可用状态。程序先枚举设备，再按需测试，分别报告设备是否存在和功能是否可用。

✓
RESOLUTION APPLIED

统一设备标识，分开检测与测试

使用稳定 ID 识别设备，通过 breflow 的 AudioDevice、DisplayWindow 和 HWInfo / Detector 获取信息。主动测试支持取消和超时，测试过程不永久修改系统默认设备。

SAFETY POLICIES
  1. P1先枚举设备，再按需执行录制或预览测试
  2. P2所有主动测试均可取消、有明确超时和可理解的失败原因
  3. P3测试过程不永久修改系统默认设备或用户设置
  4. P4诊断报告默认保护设备名称、路径和用户隐私
