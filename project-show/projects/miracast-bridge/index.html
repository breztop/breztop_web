01 / LOST CONTEXT

为什么“已经配对”仍然没有画面？

设备配对后，还需要完成地址解析、RTSP 会话和 WFD 能力协商，才能接收媒体流。不同系统的驱动时序和连接回调可能在这些阶段触发失败，需要分别记录状态和错误。

02 / SESSION ENGINE

用状态机管理连接与清理

Windows 与 Linux 的适配层提供设备、地址和连接事件，状态机按顺序推进 P2P 连接、RTSP / WFD 协商与媒体流接入。失败时记录当前阶段和协商参数，并回收该阶段的资源。
