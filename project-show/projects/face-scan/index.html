Face Scan

根据参考照片，在图片和视频中检索相似人脸

ABSTRACT / 00

根据参考照片，在图片、视频或摄像头画面中检索相似人脸。使用 YuNet 检测和 SFace 提取特征，在本地完成人脸库管理、相似度比较与结果预览，也提供浏览器摄像头接入和 HTTP API。

RESPONSIBILITY 产品设计 / 视觉算法工程 / 本地 Web 控制台
RUNTIME Python · OpenCV · YuNet · SFace INT8 · SQLite · MJPEG / HTTP API
INPUT / UNCONTROLLED REJECTED

模糊、遮挡与重复帧

模糊、侧脸和遮挡会影响人脸特征质量，视频中同一张脸又会连续出现。系统需要过滤低质量画面，减少重复计算，并让使用者调整匹配阈值。

PIPELINE / EXPLAINED ACCEPTED

先检查质量，再提取特征

YuNet 检测人脸，SFace INT8 提取特征向量，再用余弦相似度检索。每条跟踪轨迹只在首次出现、质量提升或刷新到期时更新特征；程序通过短时基准测试选择 CPU 或 OpenCV CUDA。

使用限制

  1. 01

    模型、特征与人脸库默认保存在本机，识别不依赖远程服务。

  2. 02

    相似度分数不代表身份确认概率；匹配阈值需要根据镜头、光线和样本调整。

  3. 03
