Face Scan

我的职责产品设计 / 视觉算法工程 / 本地 Web 控制台

  • OpenCV
  • YuNet / SFace
  • SQLite

把一张目标照片，变成可追踪的本地检索能力

ABSTRACT / 00

不是把摄像头喂给一个黑盒云服务，而是把检测、特征提取、轨迹去重、相似度检索和可视化收进同一条本地 Pipeline：给它一张照片，它就能在图片、视频、桌面摄像头和浏览器画面里认真帮你找人。

RESPONSIBILITY 产品设计 / 视觉算法工程 / 本地 Web 控制台
RUNTIME Python · OpenCV · YuNet · SFace INT8 · SQLite · MJPEG / HTTP API
INPUT / UNCONTROLLED REJECTED

真实现场不会配合模型。

人脸识别最容易被演示视频里的完美光线骗过：真实输入里有模糊、侧脸、遮挡、重复帧和设备性能差异。项目需要同时做到结果可解释、实时流畅、不过度重复计算，并让阈值和隐私边界始终留在使用者手里。

PIPELINE / EXPLAINED ACCEPTED

每个判断都能被追踪。

以 YuNet 完成人脸检测、以 SFace INT8 提取 embedding，并把质量门控、轻量轨迹预测和精确余弦检索串成统一 Pipeline。每条轨迹只在首次出现、质量提升或刷新到期时更新特征；CPU 与 OpenCV CUDA 自动短基准后再选路，避免为了 GPU 三个字母反而把体验跑慢。

EXPERIMENT STAGES / 03

从验证样本到实时现场

01 MVP

先把“找得到”做成可验证的工具

  • 目标照片建库与图片检索
  • 两图对比及阈值判断
  • 单目标视频 / 摄像头识别
  • 本地控制台与标注结果导出
02 V1

让实时检索更稳，也让现场信息更可读

  • 多目标与 SQLite 人脸库
  • 质量过滤、轨迹去重与抗抖动
  • 浏览器摄像头与 MJPEG 服务
  • 密度、拥挤与快速移动提示
BOUNDARIES / 04

能力边界
也是系统的一部分。

  1. 01

    本地优先：模型、特征与人脸库默认留在本机，不把隐私当作一个可选插件。

  2. 02

    阈值不是概率承诺：不同镜头、光线和人群必须用验证集重新标定。

  3. 03

    先解释再判断：低质量人脸仍可返回位置与拒绝原因，而不是悄悄消失。

  4. 04

    能力有边界：不提供活体检测、防照片攻击或法律合规自动判断，也不把轻量指标包装成完整行为分析。
