TRIBAL BATTLEFIELD ARCHITECTURE

部落战 · 3D

  • 战场管理
  • Campaign
  • 能量核心

争夺能量核心的 3D 实时战斗与战役系统

项目简介

部落战的 3D 版本，围绕能量核心组织双方攻防，并通过营地和地图连接多场战斗。单位能力由组件和状态预设组合，投射物、命中与特效分别处理。

我的职责

游戏系统设计 / 战场架构 / 数据驱动内容 / 视觉反馈

技术栈

Godot · GDScript · Component System · Data-driven · Shader · Projectile · Campaign Map

01 / IMPLEMENTATION

战役与单场战斗如何分工

系统划分

地图层负责营地与关卡推进，战场层负责一场战斗的单位、投射物和胜负。单位规则与命中、死亡等效果分别管理，便于增加兵种和调整表现。

×
实现方式

battlefield 管理单场战斗，camp / map 组织战役与关卡；component 和 modifier 预设组合单位能力。地图、模型和数值数据分别保存，投射物与效果模块独立于兵种脚本。

02 / MODULES

战役与战斗模块

模块 01

战役与营地

按营地组织关卡和地图入口，记录战役推进关系

模块 02

战场管理

管理一场战斗中的单位出生、推进、胜负与战场级事件

模块 03

能量核心

管理能量核心的争夺、防守和胜负判定

模块 04

单位组件

通过 component 与 modifier 预设配置单位行为、属性和状态效果

模块 05

投射物与命中

投射物、命中、尾迹与伤害反馈独立于具体单位实现

模块 06

效果与着色器

分别处理出生、死亡、状态和涟漪等特效，让战斗变化更容易辨认
