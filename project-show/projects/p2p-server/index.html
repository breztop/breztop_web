INCIDENT / 001

通用服务不应该知道游戏规则。

通用联机服务不能假设某一种角色、回合或关卡规则：它需要在玩家进入、离开、重复连接和房间失效时稳定维护会话，同时保持足够小的项目耦合面，让不同游戏各自拥有玩法权威。
