PLAYER / ROLE

2D 战斗系统设计 / 战役架构 / 数据驱动内容 / 战斗表现

ITEM SLOTS / STACK

Godot 2D + GDScript + Component System + Data-driven + Shader + Projectile + Campaign Map

MISSION STORY

双方从左右营地出兵，沿同一条横向战线交战，争夺中央能量核心。战役地图连接不同营地和关卡，单场战斗处理单位推进、碰撞、投射物与状态效果。

ENEMY LOGIC / 01

横版战场中的信息与镜头

近战碰撞、远程弹道、击退和减速可能同时发生。镜头需要突出当前交战位置，特效也需要让玩家看清单位在推进、僵持还是后退。
