ARCHITECTURE NOTE / 001

基于 Asio 的 C++ 网络库，通过 Channel 接口提供连接、收发和关闭操作。支持 TCP、UDP、KCP、UDP 组播与广播，包含 mDNS 服务发现、HTTP 和 WebSocket 协议处理。QUIC 与 RTP 插件列入后续计划。

N02 Channel API

PROBLEM / A

多种传输方式带来的接口差异

TCP、UDP 与 KCP 的连接方式、可靠性和消息边界不同。上层如果分别调用各自的 Socket API，就需要重复处理连接、收发、错误和关闭逻辑；服务发现还涉及网卡与地址管理。

DECISION / B

Channel 接口与协议层

Asio 负责异步 I/O 与事件循环，Channel 提供打开、读写、关闭及错误事件接口。mDNS 独立处理服务发现与公告；HTTP 和 WebSocket 在 Channel 之上解析协议，新增协议通过注册和装配机制接入。

QUIC 与 RTP 插件尚未实现，列在后续计划中。
